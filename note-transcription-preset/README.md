# 笔记转录（note-transcription）预设

发手写笔记的照片，我照图上的字原样敲成 **md**。图上的字一个字不加、不改，只动格式和换行；写完只给你一个文件。

## 它守的规矩

- **图是唯一来源**：字、词、顺序、编号、标点、错别字全照原样，图上没有的一个字也不加。
- **两遍走**：第一遍逐行照抄；第二遍才排版——标题、分节、加粗、合并折行都是默认动作，不用你额外说。
- **标题只用图上的词**：图上写大的词才能当标题，图上没有的词不造；加粗同理，只给术语、定义句的领头词和画线处。
- **不改也不删**：不补没写完的句子、不猜缩写、不修病句、不统一术语；重复的、划掉但看得清的都留着。
- **不跨页重排**：页序照你给图的顺序，不把后面的内容提前，也不合并两页的同类知识点。
- **`[?]` 不猜**：单个字认不准写最像的那个；真认不出用 `[?]` 顶一个字，排版时也不许把它猜成字或省掉。

## 用法

- 直接把照片拖进对话 → 工作区里多一个 `笔记-20261116-1930.md`
- 给路径也行：`把 D:\笔记\第三讲.jpg 转成 md` → 旁边多一个 `第三讲.md`
- 多张：`这几张是同一门课的，一张一个文件`，或者 `合成一份，叫 英语语法笔记.md`
- 改一处：`第 4 行的 [?] 是「熵」` → 只动那一处

## 输出长这样

图上写大的词才当标题；`eg` 带出来的例句加粗单独成行，译文或答案缩进到下一行。

```md
# 第三章 热力学第二定律
## 可逆过程

- 孤立系统的熵不减少
- 可逆过程 ΔS = 0；不可逆过程 ΔS > 0

**eg** 理想气体自由膨胀，求 ΔS。
  设计一条可逆等温路径。
```

## 文件放哪儿

- 图片有路径：写在图片旁边，同名 `.md`。
- 只有聊天里的图：写在工作区根目录，文件名 `笔记-YYYYMMDD-HHmm.md`。
- 合成一份：放在图片旁边，文件名用笔记主题（如 `英语语法笔记.md`），不写页码、不按页分标题。
- 同名文件已存在：像这张图的旧版本就直接覆盖，内容对不上才问你。
- 一次只写这一个 md：不建文件夹、不写摘要、不动别的文件。

## 插件清单

persona · agent-instructions · time-context · tool-fs（含 `read_image`）· tool-fs-search · tool-ask-user · present · compaction 组

## 安装

和库里其他预设一样，用 `link:` 挂到 profile 上（默认 `%USERPROFILE%\.dsh\profiles\desktop`）：

1. `<profile>\package.json` 的 `dependencies` 加
   `"@local/dsh-note-transcription-preset": "link:E:/⭐模板库/预设库/note-transcription-preset"`，
   `dsh.profile.bundles` 里加同名项。
2. 在 profile 目录跑一次 `pnpm install`。
3. 重启 DSH（或刷新 Web 界面），新会话的预设选择器里就有「笔记转录」。

## 注意

- 靠模型读图，需要当前模型支持图片输入；不支持时会直接报错，换一个能读图的模型即可。
- `read_image` 只吃 PNG / JPEG / WebP / GIF；iPhone 的 HEIC 和 PDF 先转成 PNG/JPG，或者直接把图拖进对话。
- 写到工作区外面受权限模式限制；被拦下就换个位置，或把目标文件夹加进工作区。

## 改这个预设

1. 编辑 `cordis.patch.yml` 里的 `prefix`：人格和规矩全在那儿。
2. 重开一个会话才会用上新规则；已经开着的会话仍用旧版本。
