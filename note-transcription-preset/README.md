# 笔记转录（note-transcription）预设

发手写笔记的照片，我照图上的字原样敲成 **md**。不添、不改、不总结；格式可以分层，但一个字都不动。写完只给你一个文件。

## 它守的规矩

- **图是唯一来源**：字、顺序、编号、标点、错别字全照原样，图上没有的一个字也不加，标题和加粗也只能用图上出现过的词。
- **不改也不删**：不补没写完的句子、不猜缩写、不修病句、不统一术语、不换算数字；重复的、划掉但看得清的都留着。
- **不跨页重排**：页与页按图来，不把后面的内容提前、不合并两页的同类知识点；页内可以按图上本来的分块、两栏对位、并列条目分层，只要「从上到下、先左后右」的读法不变。
- **两遍走**：第一遍逐行照抄不改字；第二遍只动标记和换行——标题层级、`-` 列表、`**eg：**` 例子、加粗、表格、空格，全部从图上取。
- **认不出就说**：单个字用 `[?]` 顶一个，排版时也不许动它；糊掉或裁掉的整段先问要不要重拍，不靠上下文编。

## 用法

- 直接把照片拖进对话 → 工作区里多一个 `笔记-20261116-1930.md`
- 给路径也行：`把 D:\笔记\第三讲.jpg 转成 md` → 旁边多一个 `第三讲.md`
- 多张：`这几张是同一门课的，一张一个文件`，或者说 `合成一份，按我给图的顺序`
- 改一处：`第 4 行的 [?] 是「熵」` → 只动那一处

## 输出长这样

图上有大标题才给 `#`；编号小节给 `##`；没有标题的话，第一行直接就是内容。

```md
# 第三章 热力学第二定律

## 1. 熵增原理

- 孤立系统的熵不减少
- 可逆过程 ΔS = 0；不可逆过程 ΔS > 0

**eg：理想气体自由膨胀，求 ΔS。**
思路：设计一条可逆等温路径。
```

## 文件放哪儿

- 图片有路径：写在图片旁边，同名 `.md`。
- 只有聊天里的图：写在工作区根目录，文件名 `笔记-YYYYMMDD-HHmm.md`。
- 同名文件已存在：像这张图的旧版本就直接覆盖，内容对不上才问你。
- 一次只写这一个 md：不建文件夹、不写摘要、不动别的文件。
- 「合成一份」时放在图片旁边，文件名用笔记主题，页间空一行；已有文件就把新内容接在末尾。

## 安装

和库里其他预设一样，用 `link:` 挂到 profile 上（默认 `%USERPROFILE%\.dsh\profiles\desktop`）：

1. `<profile>\package.json` 的 `dependencies` 加
   `"@local/dsh-note-transcription-preset": "link:C:/Users/87463/Documents/deepseek-harness/default-workspace/dsh-preset/note-transcription-preset"`，
   `dsh.profile.bundles` 里加同名项。
2. 在 profile 目录跑一次 `pnpm install`。
3. 重启 DSH（或刷新 Web 界面），新会话的预设选择器里就有「笔记转录」。

## 注意

- 靠模型读图，需要当前模型支持图片输入；不支持时会直接报错，换一个能读图的模型即可。
- `read_image` 只吃 PNG / JPEG / WebP / GIF；iPhone 的 HEIC 和 PDF 先转成 PNG/JPG，或者直接把图拖进对话。
- 写到工作区外面受权限模式限制；被拦下就照实说明需要哪个目录，别换个地方偷偷写。

## 改这个预设

1. 编辑 `cordis.patch.yml` 里的 `prefix`：人格和规矩全在那儿。
2. 重开一个会话才会用上新规则；已经开着的会话仍用旧版本。
