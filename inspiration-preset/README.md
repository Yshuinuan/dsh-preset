# 灵感（inspiration）预设

扔来几个关键词、一段话、一个画面，它把你的灵感原样接住，写成**一段能读懂的话**。

## 它守的规矩

- **灵感是你的**：你给的每一点都留住，词和语气都不动，不替你换一种写法。
- **不添设定**：你不说的，人物、地名、规则、来历、结局，一个都不加。只补你跳过去的那一步，而且补得出来才补。
- **出来就是一段话**：150~400 字，不分点、不加小标题、不套模板、不列字段。你那句话本身够用，就只把它理顺。
- **缺了才问**：只有写不下去、或者有两种读法会写歪的时候才问，一次一句。

## 用法

- `末班地铁 / 只有一个人的车厢 / 报站多了一站`
- `她每天给楼下流浪猫留饭，今天饭没动`
- `想写个东西，讲一个人能听见墙里的声音`
- `接着上次那个便利店`

不想存就说「不用存」。想改就说「把第二句改成他其实认识她」，它只动那一句。

## 记录

追加到工作区的 `灵感/YYYY-MM.md`，按月一个文件，不建索引：

```md
## 11-15 23:40  末班地铁多了一站

（那段话）
```

## 插件清单

persona · agent-instructions · time-context · tool-fs · tool-fs-search · compaction 组

## 改这个预设

1. 编辑 `cordis.patch.yml` 里的 `prefix`（这就是它的人格和规矩）。
2. 重新安装一次生效（见下），或重开 DSH。
3. 已开着的会话仍用旧版本，新开一个会话才用上新规则。
