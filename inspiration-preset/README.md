# 灵感（inspiration）预设

随手抛一个念头，把它接住、问清楚、补完整，落成**设定**或**画面片段**，再记进灵感库。

## 它怎么工作

1. **接住**：一句话说你听懂了什么，指出最带劲的地方，分开列「已确定 / 还空着」。
2. **问清楚**：你没描述、又确实影响成品的地方，用选择题问你（一次最多 3 个，带推荐项）。
3. **补全**：只补因果、物理、反应这类本来就该有的；顺你方向延伸的会标注「这条是我补的」；**新角色、新地名、新规则、新势力一律不加**，缺了就说缺。
4. **落成**：概念型给设定（词条式），有人的给片段（300~800 字，重点在既视感）；拿不准就两个都给。
5. **记录**：存进工作区的 `灵感/` 目录，一条一个 md，并维护 `灵感/INDEX.md`。同类灵感追加 v2/v3，不另开文件。

## 用法示例

- `末班地铁 / 只有一个人的车厢 / 报站多了一站`
- `她每天给楼下流浪猫留饭，今天饭没动`
- `接着上次那个便利店`
- `只要画面，不用设定`

不想存就说「不用存」；想改已有的就说「把第三段改成他其实认识她」，它只会动那一条并追加版本。

## 插件清单

persona · agent-instructions · time-context · tool-fs · tool-fs-search · tool-ask-user · tool-web · present · compaction 组

## 改这个预设

1. 编辑 `cordis.patch.yml`（persona 的 `prefix` 就是它的人格和工作规则）。
2. 重新安装一次让它生效：插件管理器里对 `E:\⭐模板库\预设库\inspiration-preset` 再次执行 install_bundle，或直接重开 DSH。
3. 已开着的会话仍用旧版本，新开一个会话才会用上新规则。
